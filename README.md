---

## 🚀 Características Principales

- 📂 **Gestión de Biblioteca:** Escanea automáticamente tus carpetas en busca de archivos de audio.
- 🎨 **Interfaz Atractiva:** Diseño visual limpio, intuitivo y optimizado.
- 🎶 **Controles Avanzados:** Reproducción fluida, modo aleatorio (*shuffle*), repetición y listas de reproducción personalizadas.
- 💻 **Multiplataforma:** Optimizado para un excelente rendimiento en sistemas de escritorio.
